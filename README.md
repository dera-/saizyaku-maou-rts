# 最弱魔王の180秒防衛戦

プレイヤー自身が「移動する本拠地」となる、ニコ生ゲーム向けランキング型タワーディフェンスRTSです。

## 操作

- 開始画面: 難易度を選び「○○で開始」を押す（初期選択はノーマル）
- 魔王をドラッグ: 魔王が指・カーソルを追従して移動
- 触媒を押す: 召喚に使う触媒を最大3個まで選択
- 触媒選択後に戦場をタップ: タップ地点へモンスターを召喚
- 選択解除: 現在の召喚レシピをクリア
- 召喚または選択解除時は魔王の移動予約を破棄し、ドラッグ入力が残りません。

## ゲームルール

- ノーマルは従来どおりの標準難易度です。魔王は5秒間被弾しなければ毎秒4HP自然回復します。
- ハードは魔王の自然回復がなく、敵HPが30%、攻撃力が25%、移動速度が8%上昇し、攻撃間隔が10%短縮されます。敵撃破・勇者早期撃破・ノーデスなど、すべてのプラス得点は2倍です。死亡減点は共通です。
- プレイ時間は180秒、160秒で勇者が出現します。
- 魔王は50HPを持ち、被弾後0.45秒は連続ダメージを受けません。
- HPが0になると死亡し、3秒後に死亡地点で全回復して復活します。
- 触媒選択中は最大5秒間、敵と味方と敵出現が停止します。
- 魔王死亡中は敵が攻撃を中止して復活地点から離れ、復活後は2秒間無敵になります。
- 魔王死亡中は全敵が個別の方向へ強制散開し、復活地点に留まりません。
- 遠距離攻撃は画面上を飛ぶ弾、近距離攻撃は斬撃線とダメージ数値で表示されます。
- 画面左右の勢力パネルで敵編成と、味方の名前・合計HP・種族・戦術を確認できます。
- 触媒未選択時は触媒欄、選択中は召喚可能な戦場全体が点滅し、操作手順を `①` `②` で案内します。
- 軍勢コスト上限は45秒ごとに `6 → 9 → 12 → 15` と拡張されます。
- 残りコストでは召喚できない触媒は暗くなり「上限」と表示されますが、所持数の `×個数` は常に確認できます。
- 街道・岩場・魔力溜まり・毒沼・墓地には召喚効果を常時表示します。
- 魔王死亡中は味方の攻撃力が30%低下します。
- 魔王と収集型モンスターはフィールド上の触媒を自動回収します。
- 敵撃破、連続撃破、魔王近距離での危険撃破、勇者早期撃破、ノーデスで得点します。
- 魔王死亡時は `1500 + それまでの死亡回数 × 500` 点を失います。

## 召喚

基本触媒は骨・牙・鉄・魔力・毒茸・魂火の6種類です。最初の触媒が基本種族、2～3個目が能力と戦術を決めます。召喚地点の街道・岩場・魔力溜まり・毒沼・墓地でも性能が変化します。45秒ごとに魔王軍が `×0.88 → ×1.15 → ×1.50 → ×2.00` と段階強化され、新規召喚だけでなく既存モンスターのHP・攻撃力・スプライトにも反映されます。中盤は通常出現間隔を短縮し、45秒以降は4～16%の確率で敵が追加出現します。終盤の敵能力倍率は最大 `×2.15`、通常出現間隔は最短2.45秒です。

代表例:

- 骨 + 鉄: アーマースケルトン
- 骨 + 魔力: スケルトンメイジ
- 牙 + 毒茸: ヴェノムハウンド
- 鉄 + 魂火: インフェルノゴーレム
- 魔力 + 魂火: レイス

## 画像素材

- `assets/sprites.png`: 魔王、味方モンスター、敵冒険者、勇者、触媒アイコンを収録した6×4の透過スプライトアトラス
- `assets/field-game.png`: 岩場・魔力溜まり・街道・墓地・毒沼を描いた1280×720のフィールド背景

画像はゲーム専用に生成したオリジナルの8-bit家庭用RPG風ピクセルアートです。スプライトはクロマキー除去後の透過PNGを使用し、Akashic Engine上ではアトラスの各セルを切り出して表示します。

## 開発

```powershell
npm install
npm test
npm run build
npm start
```

`npm start` で Akashic Sandbox を起動します。ランキングスコアは `g.game.requestSaveScore()` へ送信されます。ランキング期間中の公平性確保のため、ニコ生の `randomSeed` が与えられた場合は `g.XorshiftRandomGenerator` を使用します。

## 主なファイル

- `script/main.js`: UI、入力、リアルタイム戦闘、進行、ランキングスコア送信
- `script/gameLogic.js`: 召喚レシピ、能力補正、敵強化、スコア計算
- `script/_bootstrap.js`: ニコ生セッションパラメーターと乱数シード受け取り
- `test/gameLogic.test.js`: 純粋ロジックの自動テスト
- `assets/sprites.png`: キャラクター・モンスター・敵・触媒の画像アトラス
- `assets/field-game.png`: 8-bit風フィールド背景
